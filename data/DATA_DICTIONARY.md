# Data dictionary

The included `telco_churn.csv` is synthetic demonstration data.

| Column | Meaning |
|---|---|
| customerID | Synthetic unique customer identifier; excluded from model features |
| gender | Customer gender category |
| SeniorCitizen | 1 = senior citizen, 0 = otherwise |
| Partner | Whether the customer has a partner |
| Dependents | Whether the customer has dependents |
| tenure | Number of months with the service |
| PhoneService | Whether phone service is enabled |
| InternetService | Internet service type |
| OnlineSecurity | Online security service status |
| TechSupport | Technical support service status |
| Contract | Contract term |
| PaperlessBilling | Paperless billing status |
| PaymentMethod | Payment method |
| MonthlyCharges | Monthly service charge (demo currency units) |
| TotalCharges | Approximate cumulative charges (demo currency units) |
| Churn | Target label: Yes = churn, No = retained |

Values are generated for educational demonstration and are not collected from real people.
